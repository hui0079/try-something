# try-something

一组各自独立的本地小项目，放在同一个仓库里。每个目录单独安装依赖、单独运行。

| 目录 | 说明 |
| --- | --- |
| [a-share-paper](a-share-paper/README.md) | A 股模拟看盘。行情、助手建议和规则成交都在本地，不连接券商。 |
| [clock-out](clock-out/README.md) | 《夜巡》，像素风横版动作。 |
| [code-cat](code-cat/README.md) | 《代码猫》，走在编辑器当前行上的 IntelliJ 插件。 |
| [colony-chronicle](colony-chronicle/README.md) | 《聚落编年史》，文字聚落模拟沙盒。 |
| [follow-up-reminder](follow-up-reminder/README.md) | 回访提醒，把回访事件写入手机系统日历的微信小程序。 |
| [hot-trends](hot-trends/README.md) | 《热浪》，多平台实时热榜。 |
| [knowledge-flow](knowledge-flow/README.md) | 《知识链路》，个人知识链路图。 |
| [live-room](live-room/README.md) | 《试播间》，本机 RTMP 收流，浏览器看画面和聊天。 |
| [oa](oa/README.md) | 企业 OA，请假和报销共用一套轻量审批。 |
| [photo-guide](photo-guide/README.md) | 《取景》，按场景和器材给出拍摄参数，并给照片打分。 |
| [virtual-try-on](virtual-try-on/README.md) | 《试衣间》，上传人物照和衣物图生成试穿效果。 |
| [wechat-sticker](wechat-sticker/README.md) | 微信表情包生成器，定妆后按文案导出 GIF。 |

依赖、构建产物、本地数据库和 `.env.local` 不进仓库。密钥放在各项目自己的环境文件里。
