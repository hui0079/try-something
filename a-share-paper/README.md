# A股模拟看盘

本地模拟盘。交易时段拉取东方财富行情，Cursor 编程助手给出买卖建议，规则引擎按 A 股约束成交。账户、成交和历史收益记在 SQLite 里。不会连接券商，也不构成投资建议。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

在 [Cursor Integrations](https://cursor.com/dashboard/integrations) 申请用户 API Key，写入 `.env.local`：

```bash
CURSOR_API_KEY=cursor_...
```

改完密钥后重启开发服务器。没配密钥时页面只看行情和账户，不会下单。

## 交易节奏

- 只在连续竞价时段拉行情（09:30–11:30、13:00–14:57）。午休、收盘、周末，以及已经确认不是交易日时，不再请求。开盘后大约每 20 秒一次。优先东财，失败后改用新浪，再失败改用腾讯；一旦某个源成功，下一轮先用它，避免反复敲已经失败的东财。
- 每轮决策前从全市场取成交额、涨幅、跌幅榜。助手只能在这些榜单、自选和已有持仓里买卖，并在页面上写出选股逻辑。自选最多 10 只，可以全部清空。
- 今日盈亏按股票列出：隔夜仓相对昨收，当天买入从成交价算，当天卖出的股票卖完也保留在列表里。
- 上海时间连续竞价（09:30–11:30、13:00–14:57）才会启动助手。
- 同一时间只有一轮决策。一轮最多 4 分钟，两轮启动至少间隔 5 分钟。
- 短时间拉不到行情时，沿用最近 3 分钟内的价格。休市、行情连续中断，或指数日期不是今天时，暂停下单。
- 助手在临时目录里运行，并且不提供改文件的工具。如果仍然出现工具调用，这一轮作废。
- 初始资金 100 万。重置会封存当前账户，再新开一本；旧的收益曲线还在账户下拉框里。

数据库文件是 `data/paper.db`，不会提交到 git。
